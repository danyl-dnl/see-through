# Vision-Scribe

An AI-powered assistive vision system designed to help visually impaired individuals understand their surroundings through smart eyewear.

## Features

- Real-time camera capture using OpenCV
- Object detection (planned)
- Text recognition using OCR (planned)
- Audio feedback (planned)

## Current Progress

- [x] Webcam integration using OpenCV
- [ ] Real-time object detection
- [ ] Text recognition (OCR)
- [ ] Text-to-speech feedback
- [ ] ESP32-CAM integration
- [ ] Smart eyewear prototype

## Tech Stack

- Python
- OpenCV
- YOLO (planned)
- EasyOCR (planned)
- Text-to-Speech (planned)

## Getting Started

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd vision-scribe
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate it:

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run:

```bash
python camera.py
```
